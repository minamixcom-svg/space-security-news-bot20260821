# 🛰️ Space & Defense Security News Bot

毎朝、**宇宙・防衛・安全保障に関する最新ニュースを自動収集し、AIがその日の重要な動向を分析してメールで届けてくれるニュースダイジェストBot**です。

Google Newsから日本語・英語のニュースを収集し、Google Geminiを利用して複数の記事を横断的に分析します。

忙しいビジネスパーソンや、防衛・安全保障・宇宙領域のニュースを継続的にフォローしたい人が、**「朝メールを読むだけで、その日の主要な動きを把握できる」**ことを目指しています。

---

## ✨ Features

### 📰 1. 日本語・英語のニュースを自動収集

Google News RSSを利用して、以下のようなキーワードを中心にニュースを取得します。

**日本語**

- 宇宙
- 安全保障
- 防衛
- 衛星
- ミサイル
- 軍事

**英語**

- Space Security
- Space Defense
- Military Space
- US

日本語ニュースだけでなく、海外ニュースも対象にすることで、宇宙安全保障を国際的な視点から把握できるようにしています。

---

### 🤖 2. Geminiがニュース全体を横断分析

単純なニュースの要約ではなく、取得した複数の記事をまとめてGeminiに入力し、

- 本日の全体的なトレンド
- 共通するテーマ
- 注目すべき動向
- 宇宙安全保障上の重要ポイント

を分析します。

特に、**防衛省・航空自衛隊などの活動に関連するニュースを重点的に分析する**ようプロンプトを設定しています。

---

### 📊 3. 「ニュース一覧」ではなく「その日の潮流」を把握

メールでは、以下の構成でニュースを整理します。

#### 1. 本日の総括サマリー

その日に収集されたニュース全体から、重要なポイントを3～5行程度で整理します。

#### 2. 主なトピック・動向

関連するニュースをグループ化し、

> 「今日は何が起きているのか？」

を把握できるようにします。

#### 3. 各ニュース記事一覧

収集したニュースを日本語タイトルに統一して一覧化し、元記事へのリンクを掲載します。

---

### 📧 4. Gmailへ自動配信

生成されたニュースダイジェストはGmailのSMTPを利用してメール送信します。

メールには、

- プレーンテキスト
- HTML

の両方を用意しているため、通常のメールソフトで読みやすい形式になっています。
